# لوحة المالك (Owner console)

لوحة داخلية **للقراءة فقط**، تعرض صحة المنصة: المساحات، الخطط، استهلاك الذكاء
الاصطناعي، حالة الردود الآلية، ونبض العمال.

**لا تحتاج استضافة جديدة ولا ترحيل قاعدة بيانات**: تُبنى كتطبيق ثابت (SPA) ويخدمها
خادم الـAPI نفسه على المسار `/owner`، وتقرأ من جداول موجودة أصلًا.

## التفعيل

اللوحة **معطّلة افتراضيًا**. تُفعَّل بواحد من المتغيّرين (أو كليهما):

| المتغيّر | الاستخدام |
| --- | --- |
| `MENA_OWNER_CONSOLE_TOKEN` | مفتاح ثابت (24 حرفًا على الأقل، ويمكن وضع عدة مفاتيح مفصولة بفاصلة للتدوير). يتيحه للواجهة بدون الحاجة إلى جلسة Clerk. |
| `MENA_OWNER_USER_IDS` | معرّفات Clerk المسموح لها (مفصولة بفاصلة). تُستخدم عندما يصل الطلب بجلسة Clerk صالحة، مثل طلب من أداة خارجية أو من متصفح فيه جلسة Clerk. |

- إن لم يُضبط أي منهما، كل مسارات `/api/owner/*` تُرجع **404** كأنها غير موجودة.
- في التطوير المحلي (`NODE_ENV=development` مع `MENA_AUTH_DISABLED=true` و
  `MENA_OWNER_EMAIL`) يُفتح الوصول تلقائيًا بدون مفتاح.
- `MENA_OWNER_CONSOLE_DIST` اختياري لتحديد مجلد بناء الواجهة؛ الافتراضي
  `artifacts/owner-console/dist`.

> المفتاح يُخزَّن في الذاكرة المؤقتة للمتصفح (sessionStorage) ويُرسل في ترويسة
> `Authorization: Bearer`. استخدم مفتاحًا عشوائيًا طويلًا، ولا تضعه في أي ملف
> داخل المستودع، واستبدله إذا شككت في تسريبه.

## البناء والتشغيل

```sh
# داخل المستودع
pnpm --filter @workspace/owner-console run build   # ينتج artifacts/owner-console/dist
pnpm --filter @workspace/api-server run build      # بناء الـAPI كالمعتاد
pnpm --filter @workspace/api-server run start      # يخدم الواجهة على /owner
```

- أمر `pnpm -r build` الجذري يبني اللوحة تلقائيًا مع بقية الحزم.
- بعد البناء افتح: `https://<api-host>/owner/`
- إن لم تكن اللوحة مبنية، يعيد `/owner` رسالة 503 توضح الأمر المطلوب، ولا يتأثر
  عمل الـAPI.

تطوير الواجهة محليًا:

```sh
pnpm --filter @workspace/owner-console run dev   # http://localhost:5180 مع تمرير /api إلى 5000
```

## الأمان

- كل طلب إلى `/api/owner/*` يتحقق من الصلاحية أولًا؛ لا يوجد أي مسار عام للبيانات.
- حد أقصى للمحاولات: 10 محاولات دخول فاشلة من نفس الـIP تُوقف الوصول 10 دقائق.
- استجابة الصفحة تحمل `X-Robots-Tag: noindex, nofollow` و`Referrer-Policy:
  no-referrer`، وملف `index.html` يُقدَّم بلا تخزين مؤقت.
- الملفات الثابتة (HTML/JS/CSS) عامة لكنها لا تحتوي أي بيانات؛ البيانات كلها من
  الـAPI المحمي.
- **لا تُعرض** نصوص رسائل العملاء ولا أرقام هواتفهم ولا توكنات القنوات؛ فقط
  عدّادات ومعرّفات وأسماء مساحات.
- اللوحة قراءة فقط: لا توجد أي عملية كتابة، وبالتالي لا يمكن لجلسة مسرَّبة أن
  تعدّل بيانات أي مساحة.

## المسارات

| المسار | المحتوى |
| --- | --- |
| `GET /api/owner/session` | التحقق من الصلاحية ووضع الوصول |
| `GET /api/owner/overview` | مؤشرات عامة: مساحات، خطط، استهلاك، قنوات، طلبات، وارد 24 ساعة |
| `GET /api/owner/auto-replies?window=24h\|7d\|30d` | حالات وأخطاء طابوري الردود، التراكم، آخر الإخفاقات |
| `GET /api/owner/workers` | نبض العمال من حلقة العمال + زمن استجابة قاعدة البيانات |
| `GET /api/owner/workspaces?search=&limit=` | قائمة المساحات مع الخطة والاستهلاك والقنوات |
| `GET /api/owner/workspaces/:id` | تفاصيل مساحة واحدة |

## حدود معروفة

- تعتمد على أسماء أعمدة موجودة؛ إن غيّرت مخطط قاعدة البيانات فحدّث الاستعلامات في
  `artifacts/api-server/src/routes/owner.ts`.
- بلا إجراءات كتابة (تعطيل رد آلي، تمديد تجربة…). إضافتها تحتاج **سجل تدقيق**، أي
  ترحيلًا واحدًا.
- لا تُخزَّن سجلات مشاهدة؛ الاستخدام يُسجَّل فقط في سجلات الـAPI العادية
  (`pino`) عند الحاجة.
